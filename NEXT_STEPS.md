# Before making the repository fully reproducible

1. Confirm that the underlying research code can be publicly released under
   your institutional/project agreements.
2. Confirm ownership before adding an open-source software license.
3. Add a small openly shareable example dataset or a synthetic dataset.
4. Test the five scripts from a clean R session.
5. Document package versions (for example with `renv`).
6. Add regenerated portfolio figures to `figures/`.
7. Keep raw/private/institutional data outside GitHub.
