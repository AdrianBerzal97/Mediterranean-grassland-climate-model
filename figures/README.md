# Figures

This directory contains selected figures generated from the analysis workflow.

The figures are intended to illustrate the main modelling steps and results of the project, including:

- model calibration and validation
- observed vs. simulated grassland biomass
- relationships between climate variables and biomass production
- future biomass projections under CMIP6 climate scenarios

Published figures are not reproduced here by default. Portfolio-specific figures can be regenerated from the scripts in `src/` using data that can be legally shared.
