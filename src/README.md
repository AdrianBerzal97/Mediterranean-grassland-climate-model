# Source code

This directory contains the scripts used for climate data processing, ecohydrological modelling, model calibration and validation, and future climate scenario analysis.

The `climate_data/` subdirectory documents the manual AdapteCCa THREDDS acquisition and contains portfolio R scripts for NetCDF diagnostics and spatial extraction at the three SIMPAST sites. The extracted layer-indexed values require validated calendar interpretation and unit conversions before being used as daily SIMPAST inputs.
